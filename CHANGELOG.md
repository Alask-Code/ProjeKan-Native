# Changelog

## [1.1.0] - 2026-10-31

### Adicionado

- Vínculo de uma lista de tarefas a cada projeto, com visualização das tarefas e do progresso no modal do projeto.
- Opção de ocultar colunas no quadro Kanban; colunas ocultas aparecem como abas e podem ser restauradas na posição original.
- Seletor de data para prazos e propriedades de data.
- Temas macOS e Cyberpunk 2077, incluindo a fonte Rajdhani para o tema Cyberpunk.
- Exportação e importação de dados em CSV no perfil.
- Gerenciamento de releases em um modal próprio.

### Melhorado

- Editor de temas com prévia, paletas prontas e controles de cor e borda mais claros.
- Formulários e modais ajustados para manter campos visíveis com o teclado aberto.
- Navegação, ícones, listas de tarefas, propriedades de projeto e modal de perfil revisados.
- Fluxo de onboarding para pular a introdução quando já existem dados salvos.
- Tratamento de links vazios ou inválidos para evitar falhas ao abrir URLs.
