# Changelog

## [1.2.0]

### Adicionado

- Tema Rainbow com a fonte pixelizada Press Start 2P, também disponível no editor de temas.
- Vínculo entre projetos e listas de tarefas, com visualização das tarefas no projeto.
- Seção compacta para tarefas concluídas, com opção para expandir e restaurar todas.
- Abas para ocultar e reexibir colunas Kanban, mantendo a preferência salva.
- Campo para o documento Software Document Design com acesso ao Google Drive.
- Configurações de lembretes locais e consulta de novas versões no GitHub.

### Melhorado

- Ajustes de rolagem dos campos em modais quando o teclado está aberto.
- Melhor visibilidade de tarefas concluídas e alinhamento de componentes ao tema.
